# git-test

깃/깃허브 협업 흐름을 직접 손으로 익히기 위한 연습용 저장소입니다.

## 목표
- init → add → commit → push 까지의 기본 흐름 익히기
- branch → PR → merge 로 이어지는 협업 흐름 익히기

## 배운 것
- 깃에는 방이 3개 있다: 작업 폴더 → 스테이지(장바구니) → 저장소
- git add = 장바구니에 담기, git commit = 찰칵 확정, git push = 인터넷에 올리기
- origin은 깃허브 주소에 붙인 별명일 뿐이다
- .gitignore에 적으면 깃이 그 파일을 아예 못 본 척한다
- 브랜치는 폴더 복사가 아니라, 특정 커밋에 붙인 이름표다
- 커밋하기 전까지 내 수정은 어느 브랜치에도 속하지 않는다
